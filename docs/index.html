You bring your own Anthropic API key (console.anthropic.com). It is kept only in this browser and sent only to Anthropic, never to this site, and the questions are billed to your account: usually a few cents to about 15¢ each with Claude Opus 5, less with Sonnet 5, and follow-ups within a few minutes cost less because the season data is cached. Claude works from the same validated box scores as this dashboard: it runs Python on the season's tables for every number, and you can open the code it ran under each answer. It knows only what is in the box scores, schedule, polls, RPI and goals - not injuries, line-ups, practice or anything else not in the data - and it says so when a question goes beyond them.
